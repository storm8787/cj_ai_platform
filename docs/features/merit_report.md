# 공적조서 생성기

## 1. 기능 개요

- **목적**: 표창·포상 대상자의 공적 내용을 입력하면 공식 공적조서 양식으로 자동 생성
- **사용 대상**: 인사·총무 담당 공무원
- **처리 내용**: 공적 정보 입력 → GPT-4o로 공적조서 형식 문서 생성

---

## 2. 관련 파일

| 역할 | 파일 경로 |
|------|---------|
| 백엔드 라우터 | `backend/routers/merit_report.py` |
| 프롬프트 관리 | `backend/services/prompt_service.py` |
| 프론트엔드 페이지 | `frontend/src/pages/MeritReport.jsx` |

---

## 3. 주요 API 엔드포인트

API prefix: `/api/merit-report` (main.py에서 등록)

| 메서드 | 경로 | 설명 |
|-------|------|------|
| POST | `/api/merit-report/generate` | 공적조서 생성 |

---

## 4. 주요 데이터 흐름

1. 사용자: 대상자 정보, 공적 내용 주요 사항 입력
2. GPT-4o로 공적조서 생성
3. 후처리: 공식 문체 적용 (과거시제 서술형)
4. 응답: `MeritReportResponse` (생성된 공적조서 텍스트)

---

## 5. 환경변수 및 외부 의존성

| 환경변수 | 역할 |
|---------|------|
| `OPENAI_API_KEY` | GPT-4o 공적조서 생성 |

---

## 6. 수정 시 주의사항

- 공적조서 형식(도입부, 본문 구조, 챕터)이 프롬프트에 고정됨
- `prompt_service.get("merit_report", ...)` 패턴으로 Supabase 관리 가능
- 공문서 형식 준수: 과거시제, 3인칭 서술, 구체적 성과 수치 포함

---

## 7. 테스트 및 검증 방법

- POST `/api/merit-report/generate`에 샘플 공적 내용 전송
- 생성된 공적조서의 형식과 문체 확인

---

## 8. 향후 개선 과제

- 생성 결과 HWPX 내보내기
- 공적조서 유형별 (대통령표창/국무총리표창/장관표창 등) 형식 분리
